# Congela Mente - Sorveteria Artesanal

## Tecnologias Utilizadas
- HTML5
- CSS3 (Variaveis CSS, Animacoes, Glassmorphism)
- JavaScript (Countdown timer, Smooth scroll)
- Squeleton CSS Framework
- WOW.js (Animacoes de scroll)
- Google Fonts (Poppins)

## Funcionalidades Principais
- **Hero Section**: Apresentacao com badge "100% Naturais" pulsante
- **Countdown 24H**: Timer de urgencia para promocao relampago
- **Beneficios**: Cards com diferenciais (Natural, Artesanal, Entrega Expressa)
- **Catalogo de Sabores**: 6 sabores com precos promocionais
- **Planos de Assinatura**: 3 planos com gamificacao (Explorador, Viciado, Familia)
- **Depoimentos**: Prova social com avaliacoes 5 estrelas
- **CTA WhatsApp**: Botoes direcionando para pedido via WhatsApp
